# Diabetes ML Project

## Краткое описание проекта

ML-проект для предсказания повторной госпитализации пациентов с диабетом. Использует датасет Diabetes 130-US hospitals (1999-2008) и модель Random Forest для бинарной классификации.

## Требования к окружению

- Linux (Ubuntu/Debian)
- Python 3.10+
- uv (менеджер пакетов)

## Установка зависимостей

```bash
# Создание виртуального окружения

# Установка зависимостей из pyproject.toml
